## 確定した契約

- snapshot 保存は run 固有 object key に `if_generation_match=0` を指定する。
  `PreconditionFailed` は既存 snapshot との競合であり、無条件の上書きとして再試行しない。
- `generation`、`sha256`、object key を snapshot reference に保存し、取得は generation を
  指定してから SHA-256 を照合する。
- 検証 bucket に lifecycle rule は未設定だった。committed snapshot と未commit object の
  保持・削除 rule はタスク 7.3 の Terraform で明示的に設定する。soft delete 7 日は
  lifecycle retention の代替として扱わない。
